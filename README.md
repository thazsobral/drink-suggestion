# Drink Suggestion 🍸🍹

O **Drink Suggestion** é uma aplicação desenvolvida para ajudar usuários a descobrirem novas bebidas e coquetéis com base em suas preferências, sabores ou ingredientes disponíveis. Seja você um entusiasta da coquetelaria ou alguém procurando algo novo para o final de semana, este projeto oferece recomendações personalizadas de forma rápida e intuitiva.

## 🚀 Tecnologias

* **Linguagem Principal:** Python / JavaScript (ajuste conforme a linguagem base do seu repo)
* **Interface/API:** Streamlit, Flask ou Fastify (dependendo da sua implementação)
* **Processamento de Dados:** Pandas / Algoritmos de Similaridade
* **Fonte de Dados:** Integração com APIs de bebidas (como *TheCocktailDB*) ou dataset próprio.

## ✨ Funcionalidades

* **Busca por Ingredientes:** Encontre drinks que você pode fazer com o que tem em casa.
* **Sugestões Aleatórias:** Deixe o sistema escolher uma surpresa para você.
* **Filtros Personalizados:** Refine por categoria (Alcoólico, Não Alcoólico), tipo de copo ou sabor predominante.
* **Detalhes da Receita:** Instruções passo a passo e medidas precisas para cada sugestão.

## 📦 Como Instalar e Rodar

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/thazsobral/drink-suggestion.git
   cd drink-suggestion
   ```

2. **Instale as dependências:**
   *(Exemplo para Python)*
   ```bash
   pip install -r requirements.txt
   ```

3. **Inicie a aplicação:**
   ```bash
   python main.py
   # ou, se for um app Streamlit:
   streamlit run app.py
   ```
